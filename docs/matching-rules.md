# 现金流内部抵消匹配规则

## 概述

集团合并现金流量表编制时，需要对各子公司之间的内部现金流交易进行抵消。本工具自动读取4家子公司的明细数据，按以下规则进行匹配和抵消。

## 数据源

| 公司 | 明细文件 | 格式说明 |
|---|---|---|
| 信测集团各子公司 | 计量明细.xlsx | Sheet `1`，标记"内部"的行为内部交易，借方=付款，贷方=收款 |
| 中安 | 中安明细.xlsx | Sheet `Sheet1`，标记"内部"/"内部单位"的行为内部交易 |
| 曼哈格 | 曼哈格明细.xlsx | Sheet `3`，已预先配好对（付款方→收款方→金额） |
| 博林达 | 博林达明细.xlsx | Sheet `2`，无内部标记，从摘要字段提取对方公司 |

## 读取阶段预处理

### 计量凭证号去重

同一凭证号 + 同一方向（借/贷）+ 同一金额的记录只保留一条，防止同一笔业务重复记账。

### 曼哈格重叠过滤

曼哈格明细已配对的交易，如果在其他公司明细中也出现（相同公司对+金额），则跳过，避免重复匹配。

## 匹配流程

按优先级逐轮执行，已匹配的记录不参与后续轮次。

### 第1轮：精确匹配

- 按**金额降序**排列，大额优先匹配
- 条件：对方公司名 **精确相等** + 金额 **四舍五入到元相等**
- 判断逻辑：付款方的对方公司 = 收款方的本公司，或反之
- 匹配成功后确定收款额正负：
  - 双方CF指标代码相同 → 收款额为**负数**（视为代付/资金调拨）
  - 双方CF指标代码不同 → 收款额为**正数**（视为购销交易）

### 第2轮：宽松匹配

- 条件：公司名**包含关系**（A的公司名在B的公司名中，或反之）+ 金额相等
- 用于处理同一集团内公司全称和简称不一致的情况

### 第3轮：聚合匹配

- 将同一公司对的**多条小额记录**分组，按组**总额**匹配
- 条件：同公司对下付款总额与收款总额相差不超过1元
- 多条凭证号用分号（;）合并显示

### 第4轮：互付/互收抵消

- **互付**：A付给B 与 B付给A，同金额，双方都是付款方
- **互收**：A收到来自B 与 B收到来自A，同金额，双方都是收款方
- 这类交易实质是内部往来对转，不产生实际现金流，按互相抵消处理

### 互补对映射

付款方和收款方的CF指标通常互为互补：

| 付款方 | 收款方 |
|---|---|
| CI1.02.01.01（购买支付） | CI1.01.01.01（销售收到） |
| CI1.02.04.01（支付其他经营） | CI1.01.03.01（收到其他经营） |

| CI3.02.03.01（支付其他筹资） | CI3.01.03.01（收到其他筹资） |

## 输出说明

生成Excel包含3个sheet：

| Sheet | 内容 |
|---|---|
| 现金流内部抵消明细 | 匹配成功的内部交易对，含双方凭证号、公司名、CF指标、金额 |
| 未匹配明细 | 未配上的收付款记录，供人工核查 |
| 汇总表 | 匹配统计（对/未匹配/成功率）+ 金额汇总 |
