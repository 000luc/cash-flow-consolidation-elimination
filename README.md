# 现金流内部抵消工具

集团合并现金流量表编制辅助工具。自动读取多家子公司的明细数据，按内部交易匹配规则生成抵消明细。

## 功能

- 支持4家公司（计量/中安/曼哈格/博林达）明细文件，自动识别内部交易
- 四轮匹配引擎：精确匹配 → 宽松匹配 → 聚合匹配 → 互付互收抵消
- 输出 Excel 含3个 sheet：抵消明细、未匹配明细、汇总统计
- 简单窗口界面，双击即用

## 使用方法

### 方式一：直接运行 EXE（推荐）

1. 下载 `dist/现金流内部抵消工具_v2.exe`
2. 将 EXE 与 `明细/` 文件夹放在同一目录
3. 双击运行，选择或确认4个明细文件路径
4. 点击"开始处理"，完成后打开结果文件

### 方式二：Python 源码运行

```bash
pip install openpyxl
py cashflow_tool\__main__.py
```

### 方式三：命令行打包

```bash
build.bat
```

## 输出文件说明

生成 Excel 包含3个 sheet：

| Sheet | 内容 |
|---|---|
| 现金流内部抵消明细 | 匹配成功的内部交易对（含凭证号、公司名、现金流指标、金额） |
| 未匹配明细 | 未配上的收付款记录，供人工核查 |
| 汇总表 | 匹配对总数、未匹配数、成功率、付款/收款总额 |

## 匹配逻辑

1. **曼哈格** — 该子公司明细已自带配对，直接纳入结果
2. **精确匹配** — 对方公司名 + 金额（四舍五入到元）完全一致，大额优先
3. **宽松匹配** — 公司名包含关系 + 金额一致
4. **聚合匹配** — 同一公司对的多条小额记录合并后总额匹配
5. **互付/互收抵消** — A→B 与 B→A 同等金额的内部对等抵消

## 项目结构

```
├── cashflow_tool/           # 主程序包
│   ├── __main__.py          # 程序入口
│   ├── models.py            # 数据模型（CFRecord / MatchedPair）
│   ├── constants.py         # 现金流指标代码映射表
│   ├── matcher.py           # 核心匹配引擎
│   ├── exporter.py          # Excel 导出器
│   ├── gui.py               # 窗口界面（tkinter）
│   └── readers/             # 各公司明细读取器
│       ├── base.py          # 读取器基类 + CF工具类
│       ├── 计量.py
│       ├── 中安.py
│       ├── 曼哈格.py
│       └── 博林达.py
├── tests/                   # 测试
├── 明细/                    # 明细数据文件夹
├── dist/                    # 打包输出目录
├── build.bat                # PyInstaller 打包脚本
└── requirements.txt
```

## 开发

```bash
pip install -r requirements.txt
py -m pytest tests/ -v
```
